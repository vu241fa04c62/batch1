# SwiftCheck | Aesthetic Attendance System

A modern, AI-ready attendance system built with the MERN stack (MongoDB, Express, React, Node.js).

## 🚀 Features
- **Aesthetic UI**: Glassmorphism design with Tailwind CSS and Framer Motion.
- **Real-time Capture**: WebRTC camera integration for instant attendance marking.
- **MongoDB Integration**: Robust data persistence using Mongoose.
- **Responsive**: Fully optimized for mobile and desktop.
- **Export**: Download attendance logs as CSV.

## 📂 Project Structure
- `/backend`: Node.js/Express server with MongoDB connection.
- `/frontend`: React + Vite application with modern styling.

## 🛠️ Setup Instructions

### 1. Backend Setup
1. Navigate to the `backend` folder:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` file (optional, defaults provided):
   ```env
   MONGODB_URI=mongodb://localhost:27017/attendance_system
   PORT=5000
   ```
4. Start the server:
   ```bash
   npm start
   ```

### 2. Frontend Setup
1. Navigate to the `frontend` folder:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## 🧪 Technologies Used
- **Frontend**: React, Vite, Tailwind CSS, Framer Motion, Lucide React, Axios.
- **Backend**: Node.js, Express, MongoDB, Mongoose.
